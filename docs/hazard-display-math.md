# 状態量に基づく火災・煙の可視化

この可視化は解析支援・研究発表支援用であり、法的評価や厳密な安全認証は FDS などの高忠実度結果および数値指標を優先する。高忠実度結果も入力条件・検証・適用基準の確認が必要であり、画面の色、炎の高さ、濃淡自体に安全認証の意味はない。

## 煙の不透明度

均一な消散係数を仮定したBeer–Lambert則を、2D/3D共通の純粋関数 `computeSmokeOpacityPhysical` に実装した。

```text
T = exp(-K L)             透過率 [-]
alpha = 1 - T            不透明度 [-]
K                        自然対数基準の消散係数 [m^-1]
L                        煙中の代表光路長 [m]
```

小さいKLでも桁落ちしにくい `-expm1(-K*L)` を使用する。これは光の減衰を示すモデルであり、多重散乱、照明・波長依存性、発光、全画面の厳密な放射輸送を解くものではない。RGBの色は物理量を読むための固定スケールで、煙粒子の実際の色を予測していない。

- **Physical**（既定）: 上式のalphaをそのまま使う。CO・温度に切り替えても固定透明度を与えない。
- **Analysis**: `alpha_display = alpha^gamma`、既定 `gamma=0.55`。例えばK=0.01 m⁻¹、L=0.5 mではPhysical約0.005、Analysis約0.054となり薄い煙を確認しやすい。gammaは表示用で、質量、K、移動速度、経路、曝露・tenabilityには戻さない。K=0またはL=0なら両モードともalpha=0。

`state.viz.hazardDisplay` はUI専用設定。表示補正はPhysical/Analysisの切替に閉じ、煙・火災に新しい時計や乱数を加えていない。

### 2Dの代表長

目線高さの `eyeLevelExtinctionCoefficientM1` を優先し、Lはその階の `cellSizeMeters` とする。旧呼び出しでは `extinctionCoefficientM1` を使用する。全通路に沿った視線積分ではなく、セルの局所比較用の近似である。既定の目線は1.6 m。

fallbackの煙層厚さが明示的に0なら煙alphaも0。FDSが目線高さで非ゼロのKを提供した場合は、その観測を2Dに表示する。この場合にも3Dの上層体積を作らない。FDSの点は別のシアンの輪で位置を示す。

### 3Dの代表長と煙層

各セルの上層煙を、床面からの界面高さ `smokeLayerInterfaceHeightMeters` と厚さ `smokeLayerDepthMeters` を持つ直方体で示す。上層のK、CO、温度を優先し、目線FDSをそのまま上層へ広げない。

セル幅w、煙層厚h、単位視線方向d（yが鉛直）の中心弦長を代表長に使う。

```text
L = min(w/abs(dx), h/abs(dy), w/abs(dz))   [m]
```

ゼロ方向成分の項は無限大として扱う。h=0ならL=0。投影した直方体の凸包を1回だけ塗り、面ごとにalphaを重ねることによる同一セル内の重複減衰を避ける。異なるセル間は既存の奥行き順の半透明合成を使う。画素ごとの交差長、厳密な隠面・散乱計算ではなく、界面付近や重なる層には投影近似の誤差がある。

以前の「セル群の最大濃度を広いブロックに表示する」処理は、空セルまで煙があるように見えるため使用しない。実際のセル位置・幅で描く。非常に大きい煙場では描画負荷が増える。旧 `maxSmokeSamples` / `smokeStride` によるブロック表示は使用しない。

上層高さを持たない密度だけの旧APIは、既存互換の `K=0.32*smokeDensity` を用いる。高さは室高の上半分という表示上の仮定であり、現在の保存量モデルの層厚を置換するものではない。明示的な層厚0をこの旧互換処理で上書きしない。

## 色、単位、表示範囲

範囲は比較を容易にする固定の**表示範囲**であり、人体影響の閾値ではない。範囲外の色は飽和する。地点分析は元の値を表示し、凡例・現在の最小最大も確認できる。

| 量 | 表示範囲 | 色の意味 |
| --- | --- | --- |
| smoke density | 0–5 index | 暗いほど大きい。kg/m³ではなく既存の表示指標 |
| extinction K | 0–2 m⁻¹ | 暗いほど大きい |
| visibility | 0–30 m | 赤が短い、青が長い |
| CO | 0–1200 ppm | 青から赤へ増加（3D COは青から赤紫） |
| temperature | 20–200 °C | 青から赤へ増加 |
| heat flux | 0–10 kW/m² | 青から赤へ増加 |
| layer depth | 0–3 m | 青から赤へ増加 |
| fire intensity | 0–1 | 青から赤へ増加 |
| HRR | 0–2500 kW | 青から赤へ増加 |
| fire age | 0–300 s | 青から赤へ増加 |
| spread front | 0/1 | 現在の境界を赤で強調 |

3D densityは上層Kを既存係数0.32で割った指標、3D visibilityは `min(30,3/K)` の上層視界近似を使う。K=0では30 mに制限する。2D density/visibilityは目線側のstate値であり、FDS値があれば該当項目だけ置き換わる。上層と目線の違いは、同じstateの異なる高さを表示していることによる。

2Dの総合表示指標は従来の複合色表示を残したもの。現在の各量の表示正規化値について、最大値の70%と平均値の30%を合成する。曝露やtenabilityの分類を再計算する指標ではない。表示だけの従来の距離依存熱流束再計算を除き、定量マップは `cell.heatFluxKwM2` 等のstate値に一致させた。

## 火災の状態と描画

火炎の高さは `min(表示上限高さ, 0.12 + 2.2*sqrt(hrrKw/2500)) [m]`。これはHRRの増加を比較するための単調な**グリフ寸法**であり、予測火炎長ではない。3Dでは室高で上限を設け、2Dのグリフ半径もこのHRR寸法を参照する。描画範囲外のHRRは地点分析で確認する。

火災量セレクタのintensity/HRR/age/heat fluxは、表の範囲で正規化した値を色・グリフ強度に反映する。中心が明るく外側が弱い勾配で、セル全体を一様な火炎として塗らない。ageは現在の燃焼継続時間を表示するもので、減衰や消火を意味しない。燃料消費によるdecayを解いていないため、新しいburnStage/decayは捏造していない。

着火元は淡黄色の四角、延焼セルは橙色の輪で区別する。`ignitionTime [s]` と `spreadSourceCell` は既存の火災進展処理が記録し、描画側は更新しない。複数火元が延焼確率に寄与したときの `spreadSourceCell` は決定的な最初の寄与元であり、唯一の因果起点を同定したものではない。詳細な寄与元は既存のignition eventに残る。

spread frontは「現在燃焼していて、四近傍に非燃焼・通行可能・非壁・可燃セルがある」境界の表示。将来の着火時刻や飛火を計算しない。対角・階段を含む実際の延焼処理は既存のsolverのまま。Resetは手動火元の年齢・着火時刻を0へ戻し、延焼セルの由来も消す。

## FDSとfallbackの由来

- FDSの実測高度はシアンの輪 `○`。COや温度の色と輪の色を分離する。
- 由来overlayはFDS=シアン、fallback=灰色、mixed=紫。Mixedを選ぶと全区分を表示し、FDS/fallbackは該当区分と混在セルを表示する。
- `fdsFields` と `fireFdsFields` は実際に提供された項目の記録。集約 `hazardDataSource='fds_csv'` だけを根拠に、HRRや上層COまでFDSと表示しない。
- FDSのKから導いた煙指標、base-10光学濃度、視界も入力の由来をFDSと表示する。測定値そのものか換算値かは上記式とCSV仕様を参照。
- HRR・fireAge・fireIntensityはfallback火源シナリオ。`upperLayer*` はfallback保存量から導出した上層値。`temperatureC` と `eyeLevelTemperatureC` は同一ではない。
- 欠測は「未取得」、明示的ゼロは0。FDS解除後は由来のマーカーも除き、fallbackへ戻す。専用ページへの転送も同じ生のフィールド名と欠測を保持する。

## 操作と検証

通常画面と3D専用ページのツールバーで煙モード、煙の量、火災量、由来を選ぶ。2Dの詳細な熱流束・層厚などは左パネルの「2D定量マップ」で選ぶ。2Dは「地点分析」モードでクリック（またはAlt+クリック）、3Dはドラッグせずクリックすると、同じ分析パネルにfloor/cx/cy、煙・火災の主要値、単位、由来を表示する。3Dは最前面の床面セルを選ぶ近似で、煙表面を測定していない。複数階が重なった場合は視点を変えるか2Dで階を選ぶ。

埋込2D/3Dは同じstateオブジェクトを読む。専用ページはBroadcastChannelのスナップショットを読む閲覧専用レプリカで、独立したシミュレーションではない。階段煙矢印は正の `state.sim.verticalSmokeTransfers` の元・先と量だけから描く。表示用矢印の幅は流速の校正値ではない。

テストはK/光路長/alphaの単調性、Analysisでの低濃度強調、層厚0、FDS部分由来、単位・欠測、HRR/年齢/熱流束のグリフ、延焼境界、クリック座標、階段煙、凍結stateの不変性、転送とFDS解除を確認する。ブラウザでは実際のマップ・火元・CSVを使い、全セレクタと両画面のクリックで保存量・時刻・エージェントが変わらないことを確認する。

物理モデルの式・根拠と適用限界は [fire_engineering_model_basis.md](fire_engineering_model_basis.md)。描画の改善を物理モデルの実験検証と混同しない。
