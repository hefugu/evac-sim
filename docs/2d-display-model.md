# 2D表示の変更

2Dの入口、画像・セル座標、開始位置/出口/階段の編集、避難者・ポテンシャル表示を維持した。煙の段階的な線形透明度を廃止し、目線Kとセル幅によるBeer–Lambert表示へ変更した。Physical/Analysisの式と表示範囲は [hazard-display-math.md](hazard-display-math.md) を参照。

通常の描画順は画像・格子、煙、任意の定量マップ、HRRグリフ・由来・階段煙、避難者、選択セル、画面座標の凡例。凡例はマップ拡大率に左右されない。Analysis以外では煙を最低透明度まで持ち上げない。

`derive2DCellDisplay` はレンダリングデータだけを返す。`buildAnalysisOverlay` は現在のセル値、単位、固定色範囲、実際の最小最大を返し、表示のために火災・煙を再計算しない。色範囲は表示比較用であり、安全・死亡判定の閾値ではない。

「地点分析」モードはセルを変更せずに選択する。既存の編集モード中でもAlt+クリックで分析できる。分析パネルは描画更新時に現在のstateを読み直し、FDSの部分上書きと解除後の由来を表示する。
