# 避難エージェントのモデル選定と今回の実装

調査日: 2026-10-02。対象は建物内の歩行者避難。

## 代表的なモデル

| モデル | 人の表現・計算 | 本シミュレータでの判断 |
| --- | --- | --- |
| Social Force | 希望速度への加速、対人・壁との相互作用を連続座標で計算。[Helbing & Molnár, 1995](https://doi.org/10.48550/arXiv.cond-mat/9805244) | 既存の歩行モデルを維持。身体半径、希望速度、緩和時間、接触力、煙による減速を利用する。 |
| FDS+Evac | Social Force系の身体運動に火災環境・避難開始時間などを組み合わせる。[VTT技術資料](https://sarjaweb.vtt.fi/pdf/workingpapers/2009/W119.pdf) | 人ごとの覚知・準備時間を加える方針を採用。FDS+Evac全機能の再実装・同等性保証ではない。 |
| Steering / SFPE | Pathfinderは経路追従・衝突回避のSteeringと、密度・扉流量に基づくSFPEを提供する。[公式技術資料](https://www.thunderheadeng.com/docs/2023-3/pathfinder/technical-reference-manual/) | 経路計画・行動と歩行力学を分離する構成を参考にする。別の運動式や流量制限を既存Social Forceに重ねない。 |
| Floor-field cellular automaton | 格子上の歩行者がfloor fieldに従って移動する離散モデル。[Burstedde et al., 2001](https://www.sciencedirect.com/science/article/pii/S0378437101001418) | 大規模計算の選択肢だが、今回の連続歩行・接触力の実装を置換する理由はない。 |

年齢による身体特性と「教師・生徒・誘導者」の役割は別の概念。既存の成人・子供・高齢者の身体分布を保ち、役割に基づく行動を上位層に追加する。既存の `panic` は独自の行動仮定であり、実証された人口分類ではない。

## 今回追加した行動層

### 覚知・準備・避難

NISTは、避難前の行動時間とそのシナリオ別の校正を扱っている。[事前行動データベース](https://www.nist.gov/publications/pre-evacuation-database-use-egress-simulations)。[Evacuation Decision Model](https://www.nist.gov/publications/evacuation-decision-model)は物理・社会・心理的な手掛かりから判断過程を扱うが、今回はその方程式を実装したものではない。

本実装はユーザー入力による開始時刻モデル:

`開始遅延 = 覚知の遅れ + Triangular(最短, 最頻, 最長)`

三角分布は入力しやすい有界分布としての設計上の選択。文献が普遍的な分布や数値を保証するという意味ではない。値は訓練記録・用途に合わせて校正する。初期値はすべて0秒で、即時開始になる。「避難開始 → 個人ごとの反応時間」を選択すると有効になる。

- `unaware` → `pre_movement` → 通常の避難行動へ遷移。
- 待機中も煙・CO・熱への曝露は積算する。危険を無視して曝露を止めない。
- 待機者は対人相互作用の対象として残るが、本実装では受動的な押し流されまでは計算しない。
- 一斉開始・遠方優先を維持。遠方優先は計画された時間差出発であり、自然な反応時間分布を表すものではない。
- 実際に行動を開始した物理ステップ時刻を保存し、覚知・準備・総遅延とともにCSVへ追記。`start_s` は従来どおりシナリオ開始時刻で、総避難時間は待機も含む。

### 認知できる誘導者への追従

既存の教師・リーダー追従を局所的な認知に制限する。これは本プロジェクトの簡略モデルで、文献の群集・家族集団モデルを完全に再現するものではない。

- 子供・生徒は同じ階の避難開始済みの教師・リーダーを認知する。
- 認知距離はメートル指定（初期4m）。階のセルサイズを使って換算する。
- 視線が壁を通る場合、斜めの壁角をかすめる場合、または視線上の煙視界が人同士の距離より短い場合は追従対象にしない。
- 煙判定は各セルの視界値の最小値を使う保守的な近似。光学厚さの視線積分や人物認識実験の校正モデルではない。
- 見える既存の誘導者を優先して切替の振動を抑える。見失えば別の見える誘導者を探し、なければ自身の経路へ戻る。
- 誘導者の避難完了・転倒・階段移動中は追従解除。危険回避と最終出口接近の既存処理を優先する。

## 検証範囲と残る課題

Nodeで時間分布・状態遷移・壁の遮蔽・煙・階差・認知距離・追従切替を検証。Playwrightで待機中の曝露、開始後の移動、保存・CSV、FDS視界による追従解除と復帰を検証する。従来の火災・煙保存則・階段・混在セルサイズ・実3Fマップも回帰対象。

出口の既知・未知、家族の集合待ち、介助・車椅子などは未実装。現状の経路探索は建物全体の情報を利用する。これらは認知・身体・階段利用条件の定義と実測校正を別途必要とする。seed固定の全体実装も [既存のIssue #2計画](seed-reproducibility-plan.md) の後続作業。今回のサンプラーは注入可能な乱数関数を受け取る。
