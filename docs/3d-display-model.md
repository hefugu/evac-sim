# 共有状態の3D表示

既存 `renderer3d.js` のCanvas投影、校舎形状、階段、人、カメラ操作を維持した。変更は煙・火災の描画データ、凡例、クリック分析に限定する。モデルの計算は `simulation/core.js` と既存の火災・煙モジュールが実行する。3Dはsimulation stateを可視化する閲覧専用処理であり、独立シミュレーションではない。

## 煙層と測定点

上層の `upperLayerExtinctionCoefficientM1`、`upperLayerCoPpm`、`upperLayerTemperatureC` を使い、界面高さと層厚に沿って天井側の直方体を描く。FDS目線値を上層全体の値として使わない。煙層厚0は煙体積0となる。

Physicalの透明度は `1-exp(-K L)`、Analysisはその0.55乗。CO/温度/視界を選んでも透明度はKに基づく。Lはセル幅・煙層厚・視線方向から得る中心弦長の近似。物理モードへの最低透明度の追加や、ノイズによる体積・濃度の増加は行わない。密度・K・視界・CO・温度・由来を切替可能。

FDSは `fdsSamples[].sampleHeightMeters` の位置にシアンの輪を持つ点として描く。点の内部色は選択量、輪は由来を表す。FDSの採取点だけから上層の高さ・厚さを作らない。旧CSVの1.6 m仮定は入力処理側で通知する。

「層境界・厚さ」は界面の格子と天井までの縦線を表示する。層下面・厚さ、K/CO/温度の最大値と単位はHUDに表示する。最大値は上層とFDS点の表示データの集計であり、目線値・高さ別値を比較するときは地点分析を使う。

## 火災・由来・階段

火炎寸法はHRRによる単調な表示グリフ。火災量セレクタでintensity/HRR/age/heat flux/spread frontを切替える。中心から外側に弱くなる色の勾配、着火元の四角と延焼の輪、現在の延焼境界を追加した。熱流束モードは非燃焼セルも含む現在の熱流束を床面に重ねる。色と寸法は比較用で、予測火炎長や死亡判定ではない。

由来overlayはFDS=シアン、fallback=灰色、混在=紫。集約sourceに加えて物理量別の `fdsFields` を読み、HRRや上層値までFDSと誤認しない。

`state.sim.verticalSmokeTransfers` の正の移送量だけから、既存階段の元・先を結ぶ琥珀色の矢印を描く。線幅は直近共有ステップの移送量の表示補助で、流速ベクトルではない。階段・煙レイヤーを非表示にすると矢印も消える。

## 同期・分析パネル

同一ページの3Dは2Dと同じ `state` を読む。専用3Dページはstate bridgeが送る幾何、目線・上層の生のフィールド、FDS採取点、火災HRR・年齢・着火履歴、階段移送のスナップショットを描く。転送元を上層・目線で同名に潰さず、欠測とゼロを区別する。

クリックはカメラの逆投影レイと床面の最近交点でセルを選ぶ。5 pxを超えるドラッグ、Shift/右ボタン操作は選択せずカメラ操作を続ける。分析パネルの位置選択はUI stateに置き、煙・火災・避難者を変更しない。上の階が重なるときはカメラを回すか2Dで階を指定する。

## 近似と検証

直方体を投影した凸包へ代表光路長で一度だけalphaを適用する。既存の奥行き順合成による近似であり、画素ごとの体積レイ積分・厳密な壁遮蔽・散乱計算ではない。以前のセル群の最大値によるブロック描画は使用せず、実際の各セルの幅で描く。そのため大きい煙場では描画負荷が増える。

凍結stateの描画不変性、目線/上層/FDS点の分離、層厚0、全表示モード、床面のクリック座標、階段矢印を単体テストする。ブラウザでは実際のUI切替と2D/3Dクリック、専用ページの同期とFDS解除を確認する。

数式、表示範囲、火炎グリフのスケール、由来の判定、旧密度のみのAPIの仮定は [hazard-display-math.md](hazard-display-math.md)。この可視化は解析支援・研究発表支援用であり、法的評価や厳密な安全認証はFDSなどの高忠実度結果および数値指標を優先する。描画改善は安全認証や物理モデルの実験検証を代替しない。
