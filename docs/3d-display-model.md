# 共有煙状態の3D表示

既存 `renderer3d.js` のCanvas投影、校舎形状、階段、人、カメラ操作を維持し、煙の物理量とデータ源の表示を追加した。通常画面の3D/同時表示と `3d.html` 専用ページの両方で「煙表示」を切り替えられる。

| モード | 表示内容 |
| --- | --- |
| 消光係数 [1/m] | 既存の煙表示。上層の消光係数から代表光路長に対する不透明度を求める |
| CO [ppm] | 上層CO濃度を青〜赤紫で表示。色範囲0–1200 ppm |
| 温度 [°C] | 上層温度を青〜赤で表示。色範囲20–200 °C |
| データ源 | fallback上層を灰色、FDS測定点をシアンの輪で区別 |

色範囲は可視化用の固定スケールで、人体影響・死亡・tenabilityの閾値ではない。範囲外の色は飽和するが、HUDの最大値は実数値を表示する。

「層境界・厚さ」を有効にすると、上層煙と下層空気の境界に薄い格子を置き、境界から天井までの縦線で煙層厚さを示す。HUDには表示サンプルの境界高さの最小〜最大 [m] と最大厚さ [m] を表示する。高さは各階の床面を基準とする。大きいマップでは従来どおりセル群の最大値を選ぶ間引き表示を使うため、HUDの統計も可視化サンプルに対する値である。

## FDSの高さとデータ源

上層の表示には `upperLayerExtinctionCoefficientM1`、`upperLayerCoPpm`、`upperLayerTemperatureC` と物理煙層の高さ・厚さを優先する。目線高さのFDS連携で更新される `smokeMap`、`smokeDensity`、`coPpm` 等を上層に無条件で流用しない。

`fdsSamples` は、その `sampleHeightMeters` の位置にシアンの輪を持つ点として描く。CO/温度モードでは点の内部色を対応量で表示し、輪はシアンを保つ。FDS点測定だけで上層煙の高さ・厚さ・体積を作らない。高さを持たない旧CSVは入力処理側で1.6 m相当と明示してから渡す。上層物理状態を持たない旧来の密度のみの呼び出しは従来の煙表示へフォールバックする。

消光係数モードの不透明度は `1-exp(-K L)` で近似する。`K` は [1/m]、`L` は表示セル群幅 [m]。これは代表光路での描画近似であり、3Dレイトレーシング、詳細な放射計算、火災物理計算の追加ではない。

## 階段・2D/3D同期

`state.sim.verticalSmokeTransfers` の正の移送量に対して、既存階段とは別の琥珀色の矢印を移送元から移送先に描く。線幅は直近の共有ステップにおける移送量の視覚的強調であり、速度ベクトルや校正済み流量計ではない。階段・煙の既存レイヤーを非表示にするとこの矢印も消える。

同一ページの3Dは2Dと同じ `state` を読む。専用3Dページは既存のstate bridgeが送る幾何・煙物理量・高さ別FDS点・階段移送のスナップショットを描く。描画のフレーム更新は火災・煙・階段移動の時間を進めない。表示モードの変更もシミュレーション値を書き換えない。

`tests/renderer-modes.test.mjs` は凍結した共有stateの読み取り、上層とFDS点の分離、旧密度表示、4モード、層厚、階段矢印を確認する。ブラウザ統合テストは既存の2D/3D表示・state bridgeと併せて確認する。
