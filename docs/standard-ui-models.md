## 今回の実装

- 左側は図面・配置・条件の設定、上部は実行と2D/3D切替、結果は人数・時間とCSV。各入力にラベル・単位を付ける。小画面でも詳細の表示設定を操作できる。
- サンプル図面の読込が避難者構成を勝手に教師・生徒へ変更しない。3Fの図面だけで階段リンク・下階の図面が未設定であることを案内する。
- 標準人口は成人100%。軌跡・流れベクトルは必要時に表示する。教師・生徒などの旧プリセットは保存データの互換性を保つ。
- 火災成長率・HRR上限を実際の火源成長と補助計算へ接続し、プリセットとCSVへ記録する。上限は火源セルごと、時間は着火後の秒数。
- 煙の速度低下は連続歩行モデルへ反映。共通の低視界ランダム操舵と4方向限定ルールを除き、煙・熱リスクを経路計画に反映する。
- PR #6の重み付き出口距離場、火災近傍からの離脱、壁角・移動線分検査、無経路者の人数保持、階段着地予約と対向交通の停止対策を連続モデルへ組み込む。混在する階の実寸を使って経路・移動を計算する。
- 危険な出口にも到着直前の固定が適用される問題を修正し、安全な出口への再選択を許す。
- [操作・モデルの説明](../sim/models.html) を画面から開ける。元の機能と一般方式、簡略化の範囲を同じ画面で確認できる。

## 同等性と未実装の範囲

煙のフォールバックはセル単位の簡易モデルであり、FDSのCFDソルバーやCFASTの区画モデルを再実装したものではない。FDSは外部計算結果の取込みとして扱う。目線高さ1.6 m、量ごとの高さ線形補間、外挿なし、時刻は直前フレーム保持。空欄と測定値0を区別する。上層の体積やHRRが自動的にFDS値になるわけではない。

FDS+Evacは歴史的なモデル根拠であり、[NISTの公式告知](https://pages.nist.gov/fds-smv/) ではFDS 6.7.8以降サポート終了。今回のSocial Forceは軽量な近似実装で、3円の身体形状などFDS+Evacの全仕様は含まない。

経路の4 m火炎回避バッファ、1.1/3セルの近傍火災リスク、煙・熱のコスト重みは既存の簡略な行動ヒューリスティックで、物理的な安全離隔・規格値や製品同等の危険評価ではない。FDS量を優先し、今後の校正対象として残す。

階段は移動秒数・容量を指定するリンクで、幅・勾配・上下方向による校正済み流量モデルではない。完全なFED、車椅子・介助、家族の集合、未知の出口の探索、材料に基づく延焼は未実装。乱数seedを利用者が固定する全体機能も別途課題。燃料収率・燃焼熱・火源面積・HRR上限・人口はシナリオ値で、普遍的な推奨値ではない。

## 検証

Nodeで歩行・壁角・単位・煙保存・階段交通・火災成長を確認。ブラウザで実際の画像読込、配置操作、避難、危険回避、複数階段、FDS部分上書きと解除、反応時間、保存・CSV、2D/3D、100回試行、停止・リセット、狭い画面を確認する。

ローカル結果: Node **128/128**、Playwright **30/30** が成功。ブラウザ全体は1 workerで約2.2分。幅1 mの屈曲廊下、24人・2本の階段、火災設定の保存とCSV、FDS視界のみの速度低下、実3F図面の長距離避難、混在セルサイズの表示階非依存、100回試行、画面上部の実行とCSV保存、390 px幅と独立3Dを含む。

旧0.5 m幅の点粒子用の廊下試験は、成人身体直径の参照分布と合わないため、身体を持つ歩行者が通れる実寸を指定する。画面上の移動を見せるために身体幅を消す変更はしていない。

公開mainとローカル・PRの検証結果は分ける。Vercelの本番更新はmainへの反映後になる。
